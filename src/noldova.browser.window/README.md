# @noldova/browser.window

The browser module's window part, in Angular: the page documents that show web pages in the app's window, the command that opens one, the status-bar item that says each agent's open pages, their controller and the tracker of the place the page shows in.

It exports the window part, `windowPart`, which the module's own package, [`@noldova/browser`](https://github.com/noldova-com/browser/tree/main/src/noldova.browser), re-exports from its `./window` and pins at its own version.
[documents/ARCHITECTURE.md](https://github.com/noldova-com/browser/blob/main/documents/ARCHITECTURE.md) says how it is built, and the [README](https://github.com/noldova-com/browser#readme) how to build and test it.
